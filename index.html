A) ทำครั้งแรก (ครั้งเดียว)

              
    
                
  1. กดเมนู ⚙️ → วางลิงก์ Apps Script ที่ลงท้ายด้วย /exec → บันทึก
    2. 
                
  2. กด “ทดสอบ API” ถ้าขึ้น pong = พร้อมใช้งาน
    3. 
                
  3. กด “เริ่มสแกนใบหน้า” (ระบบจะพยายามโหลดรายชื่อ + ขอ GPS ให้)
    4. 
              

            


            

              
B) สแกนใบหน้า (วิธีหลัก)

    2. 
                
  2. รอขึ้น “ขั้นตอน 2/3 พบชื่อ…”
    3. 
                
  3. กด “ยืนยันแล้วเช็คอิน” → เสร็จ ✅
    4. 
              

            


            

              
C) บันทึกด้วยมือ

    2.

    3. 
                
  3. กรอกเหตุผล → กด “บันทึกด้วยมือ”
    4.
